## dev_html
本文件夹下的项目为项目的html原型，用以验证本项目的基本玩法

### 2026.11.22 初始化与整体更新
1. 确定了游戏的整体美术风格为Q版极简风
2. 为游戏添加了占位的两个人物的走路素材
3. 为游戏添加了占位的武器素材
4. 确立了游戏的基础战斗系统，并添加了一个纯随机生成地图用以验证
5. 为游戏添加了背包系统，当前的背包系统还需要更改

### 2026.11.23 美术重新定调：低多边形 + 三渲二
1. 诊断：人物 / 敌人 / 武器 / 地板 分别用了 4 套描边、明暗、色温语言，所以"不像一层"
2. 新增整场参照图 `dev_html/art_draft/artbible/`：同一套低模规范、同一套 cel 材质、同一套光位
3. 规范与调色板写入 `dev_html/ART-BIBLE.md`，可复现脚本 `dev_html/_blender/artbible_scene.py`
4. 现有素材（player.png / weapons_lineup.png / floor_tiles.png / zombie 帧）降级为占位，
   下一步按新规范重出（角色帧、武器 40px 图标、地砖平铺图）
5. 角色定稿为"四块式"极简模型：一个方块=头、一个方块=身体、两个方块=腿，不建手臂，
   单角色 40–80 面；整场 372 个 mesh / 约 6.3 千面
6. 角色表：玩家 = 潜行者（人类）/ 突击手（人类）；敌人 = 僵尸 / 干尸（新增）/ 喷吐僵尸。
   玩家不再使用机器人造型


### 2026.11.23 3D 化动工（dev_web3d）
1. 新增 `dev_web3d/`：零依赖 WebGL 渲染器 + 可玩竖切片（移动/射击/敌人/撤离）
2. 美术直接复用 artbible 的方块规范：单角色 4 个方块，整场约 1.7 万顶点
3. 镜头俯角可切 45/55/62/70（`[` `]`），也可用 `?pitch=45` 直接指定
4. `dev_html/` 2D 原型保留不动，作为对照
