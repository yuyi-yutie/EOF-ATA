# artbible —— 项目美术参照

这个文件夹是 **EOFATA 的美术基准**，不是可用的游戏素材。任何新资产都先跟这里对齐，再进 `assets/`。

| 文件 | 内容 |
| --- | --- |
| `01_scene_hero.png` | 3/4 全景定调图：人类玩家 / 敌人 / 武器 / 地面 / 墙体 / 道具在同一套光与材质里 |
| `02_scene_closeup.png` | 近景：检查描边粗细、色阶硬边、面数 |
| `03_characters.png` | 角色对照：潜行者 / 突击手 / 僵尸 / 干尸（正交正面，同光同位） |
| `04_weapons.png` | 五把武器对照（同一枪族，只换枪口模块） |

规则见 `../ART-BIBLE.md`，可复现脚本 `../_blender/artbible_scene.py`。

**这四条判断"是不是同一层"的硬标准：**

1. 所有物件都是低多边形块面，没有平滑、没有圆角、没有贴图花纹。
2. 所有材质都是同一条 cel 节点链（三档硬边色阶，暗部同一个冷偏移配方）。
3. 所有物件共用同一套描边（粗细按物族分级）和同一组三灯。
4. 同一个色相只出现在"亮/中/暗"三档里，发光只留给面罩 / 口腔 / 可交互物。

> 结论：**换一个物件时，只能改形状和配色，不能改上面四条。**
