# EOFATA — 2D 撤离射击原型 · 设计方案 v1

> EOFATA = EndOfFuture : ATA
> 一句话：在未来尽头的废弃设施里，用五种"物理模态"武器杀出重围，搜刮数据，活着撤离。

---

## 0. 设计目标

| 目标 | 说明 |
|---|---|
| 上手成本 | 3 分钟内理解移动 / 射击 / 拾取 / 撤离 |
| 单局时长 | 6–8 分钟（可压缩到 5 分钟速通） |
| 核心张力 | **贪婪 vs 风险**：多搜一间房 = 多一份数据，也多一次被围 |
| 武器差异 | 五把枪必须是"五种玩法"，不是五种数值皮肤 |
| 交付形态 | 纯前端、零依赖、双击 `index.html` 即玩 |

---

## 1. 技术形态

- **渲染**：Canvas 2D，逻辑分辨率 `1280×720`，按窗口等比缩放（letterbox），适配 DPR。
- **视野**：`CFG.ZOOM`（默认 `1.25`）把世界放大绘制，实际可见范围 = `1280×720 / ZOOM`；相机、瞄准换算、小地图视口框都按这个视野尺寸计算。
- **循环**：固定步长 60Hz 逻辑更新（累加器），渲染每帧一次。
- **零依赖**：无构建、无 CDN、无外部字体；美术为本地 PNG（`assets/`），其余用几何图形 + 发光描边绘制。
- **脚本加载**：经典 `<script>` 顺序加载（非 ES Module），保证 `file://` 双击可运行，也兼容 http 打开。
- **音频**：WebAudio 实时合成音效（无音频文件），`M` 静音。
- **存档**：`localStorage` 仅存最佳战绩与设置（若需要局外仓库见文末问题 B）。

## 2. 视觉与 UI 风格

**基调**：**暖色瓷砖**——米色地砖 + 暖白墙体（深色侧面 + 黑描边），参考 `art_draft/tiles/参考图.png`；障碍物靠"暖白 + 深色墙脚"从地砖里跳出来。浅色特效（激光、白弹、粒子）统一加深色衬边，保证浅底可读。

| 用途 | 色值 |
|---|---|
| 背景 / 虚空 | `#ddcdb2`（地板贴图兜底色） |
| 地面 | 地砖贴图 `assets/floor_tiles.png`（4 变体，64px = 2 格分块随机铺），主色 ≈ `#ccb39f` |
| 障碍物实体 | 墙面贴图 `#ede3d6`，下沿侧面 `#3d3e40` |
| 障碍物轮廓 | `#241f1c`（2px 黑描边） |
| 主色（UI / 数据 / 警示条） | `#ffb648` |
| 护盾 / 撤离 | `#0a6e91`（白底上用深青） |
| 血量 / 危险 | `#ff5a4d` |
| 稀有度 绿/蓝/紫 | `#5ad46a` / `#4d8bff` / `#b96bff` |

五种武器的识别色（低饱和，不破坏工业感）：

| 武器 | 色值 |
|---|---|
| 声学 | `#ffb648` 琥珀 |
| 光学 | `#9fe6ff` 冷白青 |
| 热学 | `#ff7043` 炽橙 |
| 力学 | `#e8e8e8` 白 |
| 电学 | `#b28cff` 紫 |

**画面语言**

- 所有实体 = 几何体 + 1–2px 描边 + `shadowBlur` 外发光；不描边纯填充。
- **人物**：`assets/player_walk.png` 5×3 = 15 帧行走循环（每格 198×317，单朝向，行优先 0→14）。以脚底为锚点，只随准星左右翻转；走路 14 帧/秒、奔跑 19 帧/秒；不移动时改用 `assets/person.png` 站立图。分层顺序「人物 → 武器」，枪压在人物身前。
- **武器**：五把各一张侧视图（统一枪口朝右），以握把（扳机手位置）为旋转轴做 360° 旋转；朝左时贴图上下翻转，避免倒置。HUD 武器槽与右下角面板复用同一张图。
- 地面：米色瓷砖，砖缝自带在贴图里，整张预渲染时用 pattern 平铺。
- 障碍物：暖白墙面 + 下沿 9px 深色侧面 + 2px 黑描边；墙脚在地板上压一层 16px 软阴影，轮廓即碰撞边界。
- 叠加层：CSS 扫描线（`repeating-linear-gradient`）、四角暗角、低血量时色差抖动（红/青分离 1–2px）。
- 受击：屏幕边缘径向红闪 + 相机 4px 抖动；命中敌人：白色 hit flash + 伤害数字 + 火花粒子。

## 4. 单局流程

```
大厅（配装 / 花数据买初始弹夹） → 空降舱（出生） → 开放式场地搜刮 / 交战
    → 找到撤离台 → 站入范围按住 6s → 撤离成功结算（剩余数据存入账户）
    ↘ 死亡 → 失败结算（背包内未撤离战利品全部丢失，账户不受影响）
```

- 没有倒计时压迫，压力来自**弹药有限 + 背包有限 + 群落敌人**。
- 撤离台 2 处，位于场地右侧上下两片开阔地；站入后进度环推进，离开后快速回落。
- 撤离过程中附近敌人会被吸引过来（收尾压力）。

---

## 4.1 大厅与配装

- 游戏启动后进入**大厅**，不再直接开局；**武器不跨局保存**，每次进局都要重新选 2 把，进局后选择清空。
- **角色**：大厅左上「选择角色」二选一（潜行者 / 突击手），选择存在 `localStorage: eofata.char`，跨局保留；角色只影响外观（行走帧表 + 站立图），数值完全一致。
- **跨局数据账户**（`localStorage`，新档 300 NB）：
  - **撤离成功**才把本局剩余数据存入账户；
  - 死亡 / 放弃行动不影响账户；
  - 局内数据从"携带数据"开始。
- **携带武器**：从 5 把中选 **2 把**，其余三把当局锁死（背包制作列表显示"未携带"）。
- **初始弹夹**：每把可配 **0–3 个**，按武器造价扣账户（25–70 NB/夹）。
  - 配给 **≥1 个时枪内直接上弹**，其余为备弹（上限 2）；
  - 0 个 = 空枪，需要先搜刮数据在背包里压制弹夹。
- **携带数据**：从账户中划出一笔带进局，必须是 **100 的倍数或 0**；撤离后未花完的退回账户，死亡则丢失。
- 局内键位重排为 `1` / `2`，对应携带的两把武器。

---

## 4.2 仓库

- **12 × 8 = 96 格**的大网格，与背包同规则：物品按自身尺寸占格，自动摆放，跨局保存（`localStorage`）。
- 撤离成功时，背包中的**全部物资**转入仓库；死亡则本局物资丢失。
- **右键单件 → 立即分解**（不消耗时间），价值直接进账户；也可"全部拆解"。
- 仓库只做存放与分解，不提供局内使用；没有仓库扩容 / 武器存放。

## 5. 地图生成（开放场地）

- 网格 **128 × 96** 瓦片，瓦片 32px → 世界 **4096 × 3072**（约 3.2 屏宽）。
- **基础是一整片空地**（只保留地图边界墙），不再生成地牢房间与走廊。
- **建筑**：约 **18 座空心建筑**（9–16 × 7–12 格），每座由 3–4 组 **L 形墙段** 围合而成，四边留大开口供进出；约一半开口中间补一小段墙，形成两个门洞；约 60% 带内部隔断或柱子。墙体只挡视线与子弹，内部仍是可走地面。
- **小型掩体**：96 个左右 1×1 / 2×1 / 2×2 货箱，散布在开阔地与建筑内部，彼此至少留 2 格通道。
- 种子化 RNG（`mulberry32`），同一 seed 生成同一张图；生成后做连通性检查，被围死的空地会换种子重试（最多 8 次），实测可达率 100%。
- **出生点**：场地左侧空地，周围 7×7 格无遮挡。
- **撤离点**：右侧上下两片开阔地各找一处 7×7 无障碍区域，彼此至少相隔 700px。
- **战利品**：全场地随机撒 **82 个**，避开墙体与撤离台；品质按"离出生点越远越可能稀有"加权（用出生点 BFS 距离场）。
- **敌人**：**群落式**生成，13 个巢穴（含 2 个精英巢）、普通巢 3–4 只 / 精英巢 2–3 只，共 **52 只**；巢穴间距 ≥340px、离出生点 ≥620px。
- **渲染**：整图预渲染到离屏 Canvas（一次），每帧只 blit 视口；地面按 64px（2 格）分块挑地砖变体，墙体用 `wall_tile.png`（4 格 = 128px 平铺）铺面，墙脚带投影；墙厚 1 格。

## 6. 玩家

| 属性 | 值 |
|---|---|
| 半径 / 走路 / 奔跑 | 12px / 122 / 200 px·s⁻¹ |
| 本体血量 | 100 |
| 护盾 | 60，脱战 **4.5s** 后以 **30/s** 自动回满 |
| 耐力 | 100；奔跑消耗 **21/s**，松开 0.7s 后以 **17/s** 回复；耗尽强制走路，回到 **28** 才能再次奔跑 |
| 碰撞 | 圆 vs 瓦片 AABB，分轴解算（贴墙滑行） |

**伤害结算（关键规则）**：护盾**全额抵免**——一次攻击先把护盾打空，溢出部分**不穿透**到血量；只有"护盾已为 0 时被命中"才扣血。护盾相当于每轮交战的免费缓冲层，血量才是真资源。

**移动手感**：加速度 2400 px/s²，摩擦 12/s，起步/急停有轻微惯性但跟手。按住 `SHIFT` 奔跑；耐力条常驻 HUD 左上角，与护盾/血量共用同一套斜切条样式（琥珀 → 低耐力（<30%）橙 → 耗尽红并脉冲）。

## 7. 武器系统

五把枪对应五种物理模态，共用"弹夹 / 备弹"框架，差异体现在**弹道与命中后的行为**。

| # | 武器 | 模态 | 弹夹 | 备弹上限 | 射速 | 换弹 | 弹夹造价 | 单发伤害 | 核心机制 |
|---|---|---|---|---|---|---|---|---|---|
| 1 | 共振霰弹 | 声学 | 6 | 12 | 0.75s | 2.4s | 40 NB | 40→16 | 扇形冲击波，群体 |
| 2 | 棱镜激光 | 光学 | 6 | 12 | 0.50s | 2.0s | 60 NB | 46 | 瞬时反射光束，路径全伤 |
| 3 | 辐射投射器 | 热学 | 5 | 10 | 0.90s | 2.6s | 70 NB | 10 + 持续 | 落点辐射场 |
| 4 | 轨道步枪 | 力学 | 12 | 24 | 0.28s | 1.8s | 25 NB | 34 | 朴素高伤单体 |
| 5 | 电弧枪 | 电学 | 8 | 16 | 0.45s | 2.0s | 60 NB | 22 | 连锁 3 跳 |

### 逐把实现要点

**① 声学 · 共振霰弹**
开火瞬间在枪口生成 **65° / 260px 扇形**，无需子弹飞行：扇形内所有敌人立即结算。
伤害按距离线性衰减 40 → 16；近距离附加 120px 击退与 0.15s 硬直。
视觉：3 层错位弧线 + 空气扭曲环 + 强后坐（准星扩散 +28）。

**② 光学 · 棱镜激光**
开火瞬间用步进射线（2px 步长）算出**完整反射折线**：最多弹墙 3 次，总光程上限 2600px。
整条路径**一次性结算**：所有与折线距离 ≤ 半径的敌人同时受伤，单发 **46**，每弹一次衰减 ×0.85（39 / 33 / 28）。
视觉：高亮白色核心 + 青色外发光，反射点画白色光斑，整条光束在 0.26s 内淡出。
定位：走廊/开阔地清场利器，弹药少（6 发）、射速慢（0.5s），打空后换弹成本高。

**③ 热学 · 辐射投射器**
发射 620 px/s 慢速弹体，命中敌人/墙后在**命中点**生成半径 76 的辐射场，持续 3.2s。
每 0.25s 对场内敌人造成 3.5（≈14 dps）；直击额外 10。
同一点最多叠加 2 个场（上限，防刷）；场内敌人移速 ×0.85。
视觉：脉动的品红圆域 + 上升粒子 + 边缘噪声。

**④ 力学 · 轨道步枪**
1800 px/s 高速弹，单目标 34 伤害，命中即消失。
后坐最小、精度最高，是"稳定输出"的基准线；对单目标 DPS 最高（≈121）。

**⑤ 电学 · 电弧枪**
弹体命中后，向 150px 内最多 3 个其他敌人链式跳跃，每跳伤害 22 → 13 → 9 → 6。
跳跃有 0.06s 间隔的折线闪电视觉，链式目标优先"未被本次链命中最近者"。
视觉：白紫折线 + 目标短暂麻痹（0.1s 停步）。

> 平衡目标：单体 DPS 力学最高；群体效率声学/电学最高；光学在中距离多目标最优；热学负责"封路/消耗"。

## 8. 弹药与换弹

- 每把枪独立维护 **弹夹内子弹** 与 **备弹（弹夹个数，上限 2）**。
- **R 换弹**：备弹 ≥ 1 且弹夹未满 → **丢弃当前弹夹余弹** → 消耗 1 个备弹弹夹 → 弹夹补满，耗时 `reloadTime`。
- 主动设计：**打空再换**才不浪费；空弹夹开火只响"干击"并提示 `[R] 换弹`。
- **弹夹只能制作**（地图不掉弹药）：背包内选武器 → 支付数据 → 1.5s → 该武器备弹 +1（满 2 时禁用）。
- 备弹为 0 时武器槽灰显并标 `EMPTY`。

## 9. 敌人

两种僵尸，分近战 / 远程，主打"群落压迫 + 逼迫走位"。都是侧视逐帧动画（walk / run / attack），单朝向（朝右），面向左时水平镜像。

| 类型 | 血量 | 速度 | 伤害 | 半径 | 动画 |
|---|---|---|---|---|---|
| 僵尸 Zombie | 45 | 112 | 8（近战） | 11 | 巡逻 walk（14 帧，去掉和第 1 帧重复的第 15 帧）/ 追击 run（6 帧，原始 10 帧里有多组重复姿势、首尾差异大，去重后重排成平滑循环），**按实际位移推进**（一圈 50px）；攻击 attack（26fps，36 帧，第 17 帧出伤，整套 ~1.39s 不移动） |
| 喷吐僵尸 Zombie Y | 95 | 76 | 12（弹体） | 13 | 移动 walk（18 帧），**按实际位移推进**（一圈 58px）；攻击 attack（18fps，12 帧，第 3 帧吐出酸弹，整套 ~0.67s 不移动） |

- **群落**：13 个巢穴、普通巢 3–4 只 / 精英巢 2–3 只，共 **52 只**；每 5 巢中有 1 巢是**精英巢**（喷吐僵尸占一半）。
- **攻击锁定**：一套攻击动作期间完全不能移动（前摇 + 出伤 + 后摇），播完才进入冷却；出伤前会有一圈收紧的红环作为预警。
- **步态同步**：走/跑动画不用固定帧率，而是按每帧实际位移推进（`stride` = 一个完整循环前进的像素，在 `js/sprites.js` 的 `ENEMY_ART` 里配），速度变化时脚不打滑；攻击动画仍按时长播放。
- **三渲二**：角色、敌人、武器、地砖/墙面**全部来自 Blender**（`_blender/render_zombie.py`、`render_player_toon.py`、`render_weapons_toon.py`、`render_tiles_toon.py`；源文件在 `blender_draft/*.blend`），统一的 cel 材质 + alpha 膨胀描边，风格一致。：方块模型 + 骨架 + 常量 ColorRamp 的硬边明暗 + 正交相机；描边用 alpha 膨胀在贴图阶段生成。因为是同一个模型渲染，动作天生连贯，不会再出现 AI 逐帧图那种"首尾不接"的问题。
- **群居游荡**：未警觉时围着巢穴中心做缓慢环形游走（各自有相位与半径），看起来像一群在原地打转。
- **群体警觉**：任何一只被噪音惊动、被看见、或被击中，**整个巢穴同时进入追击**；受伤也会唤醒同伴。
- **感知**：视线 460px（瓦片射线遮挡判定）+ 噪音（开枪 520px，声学武器 760px）。
- **追击**：**BFS 流场**——每 0.22s 以玩家所在瓦片为源计算全图距离场，敌人沿梯度下行 + 同伴分离力（避免叠成一坨）。
- **近战攻击**：接触且冷却就绪 → 前摇 → 命中判定 → 冷却。
- **冲锋**：进入 120–520px 且视线通畅 → 原地蓄力 0.52s（红色前摇环 + 双翼张开）→ 锁定方向高速突进 0.3s，撞到玩家造成 20 并把自己弹开；冷却 2.6s。
- **远程**：与玩家保持 230–420px，太近后退、太远靠近、中距离绕圈；视线内每 2.2s 发射一发酸弹（可被墙挡下）。
- **脱战**：玩家距离 > 1150px 持续 4s 后回到巢穴游荡。
- 死亡：粒子爆散；**不掉落**（保持"搜刮"为唯一收益来源）。

## 11. 背包

- **6 列 × 4 行 = 24 格**固定方形网格；物品有 **1×1 / 1×2 / 2×1 / 1×3 / 3×1 / 2×2 / 2×3 / 3×2** 等尺寸（按物品种类固定）。
- **拖拽移动**：按住物品拖动，松手放下；占用冲突或越界会退回原位。拖动时目标格显示绿/红高亮框。
- **`R` 旋转**：拖动中按 R 旋转 90°；不在拖动时对悬停/选中的物品原地旋转（空间不足会提示）。
- `TAB` 开关；面板右侧固定功能区：
  - **制作弹夹**：5 个武器按钮，显示造价与当前备弹 `1/2`。
  - **治疗**：`50 NB / 3s` → 血量回满（护盾不受影响，自行回充）。
- **右键分解**：开始后显示进度条，进度按**真实时间**推进；**移动会打断**（进度清零，物品保留）。
- 左键选中显示物品详情（名称/品质/数据量/尺寸/分解耗时）。
- 分解完成：物品消失 → `数据 += 价值` → 琥珀色飘字 `+86 NB`。
- 容量计数显示"已占用格数 / 24"，例如 2×2 占 4 格。

> **已确认**：背包**不暂停**世界——分解与治疗都要顶着敌人完成，这是核心风险来源。

## 12. 数据经济

- **账户**：跨局保存（localStorage，新档 **300 NB**）。
- 局内初始数据 = 大厅选择的**携带数据**（100 的倍数，从账户划出）；撤离退还未花完部分，死亡丢失。
- 收入：局内分解收集物；仓库瞬时分解（把存货转成数据）。
- 支出：局内弹夹（25–70 NB）、治疗（50 NB）；大厅配给初始弹夹（25–70 NB/夹 × 0–3）。
- 单局期望：拾取 ≈ 20 件 → 毛收入 600–900 NB；弹药+治疗支出 300–500 NB；撤离净存入 200–500 NB。
- 显示格式：`1,240 NB`（千位分隔，等宽数字）。

## 13. 撤离与结算

- 撤离台半径 66，站入后进度环 6s；离开后进度快速回落。
- 撤离期间每 0.7s 惊动半径 470px 内的敌人（收尾压力）。
- **成功**：结算面板 —— 撤离成功 / 击杀数 / 拾取件数 / 剩余数据 / 用时 / 最佳纪录；剩余数据**存入账户**，背包物资**转入仓库**。
- **失败**：红色故障风面板 —— 信号中断 / 丢失数据量；背包物资与未花完的携带数据丢失，**账户与仓库不变**。
- 结算界面：`R` / `ESC` 返回大厅。

## 14. 反馈与打磨

- **音效（WebAudio 合成）**：五种差异化枪声（声学低频爆、光学高频啸、热学闷响、力学脆响、电学噼啪）、命中、拾取、换弹双段咔嚓、撤离嗡鸣、受击。
- **打击感**：命中 2 帧顿帧、伤害数字上飘、击杀粒子、相机抖动（开火/受击/爆炸分级）。
- **引导**：开局 3 行提示（WASD 移动 / F 拾取 / 找撤离台），3 秒淡出。
- **性能预算**：≤ 60 敌人、≤ 160 子弹/粒子组，单帧逻辑 < 4ms。
