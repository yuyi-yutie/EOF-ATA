# EOFATA — 2D 撤离射击原型

> End of Future : ATA
> 纯前端 Canvas 2D 原型，无依赖、无构建；人物与武器贴图由 Blender 渲染后内置在 `assets/`。双击 `index.html` 即玩。

---

## 运行

**方式一（最简单）**：直接双击 `index.html`。
脚本使用经典 `<script>` 加载，不依赖 ES Module，所以 `file://` 下也能跑。

**方式二（推荐，音效更完整）**：

```bash
# 在 dev_html 目录下
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

调试参数：

| 参数 | 作用 |
|---|---|
| `?autostart=1` | 跳过大厅直接开局（默认携带 轨道步枪 + 棱镜激光，各 1 夹，不扣账户） |
| `?seed=12345` | 指定地图种子（复现同一张图） |
| `?bag=1` | 调试：往背包塞入各种尺寸的样品（配合 `autostart`） |
| `?stash=1` | 调试：仓库为空时塞入一套各品质样品 |
| `?fight=1` | 调试：开局传送到精英巢穴旁并惊动它们 |

## 大厅与配装

- 启动后进入**大厅**，不再直接开局；**武器不跨局保存**，每次回大厅都要重新选 2 把。
- **账户数据**跨局保存（`localStorage`，新档 300 NB）：**撤离成功**才把本局剩余数据存入账户；死亡 / 放弃行动账户不变。
- 每局携带 **2 把武器**，其余三把锁死（背包里显示"未携带"）。
- **初始弹夹**：每把可配 **0–3 个**，按武器造价扣账户（25–70 NB/夹）。
  - 配给 **≥1 个时枪内直接上弹**，剩余作为备弹（最多 2 个备弹）；
  - 配 0 个也能进，但需要先搜刮数据制造弹夹。
- **携带数据**：从账户里选择带进局的数据，必须是 **100 的倍数或 0**；撤离后未花完的部分退回仓库。
- 键位重排为 `1` / `2`，分别对应携带的两把武器。

---

## 仓库

- 大厅点"仓库"打开：**12×8 = 96 格**的大网格，物品按尺寸占格（1×1 / 2×2 / 2×3 …），跨局保存。
- 撤离成功时，背包里的**所有物资**自动入库；死亡则全部丢失。
- **右键单件 → 立即分解**（不消耗时间），数据直接进账户；也可以"全部拆解"。
- 仓库里的物品只是存放，不参与本局战斗。

## 操作

| 输入 | 行为 |
|---|---|
| 大厅：点击武器卡 / `+` / `-` | 选择携带武器、调整弹夹配给 |
| 大厅：携带数据 `+` / `-` / 全部 | 以 100 为单位调整带入局的数据 |
| 大厅：仓库按钮 | 打开仓库；右键物品立即分解，`ESC` 关闭 |
| 大厅：`Enter` | 进入设施（需选满 2 把且数据足够） |
| `W A S D` | 移动（默认走路 122） |
| `SHIFT`（按住） | 奔跑 200，持续消耗耐力；耐力耗尽强制走路 |
| 鼠标 | 瞄准 |
| 左键 | 射击（按住连发） |
| `1` / `2` | 切换携带的两把武器（也可点击左下武器槽） |
| `R` | 换弹（**丢弃当前弹夹余弹**） |
| `F` | 拾取附近收集物 |
| `TAB` | 打开/关闭背包 |
| 左键拖动（背包内） | 移动物品（松手放下，冲突则退回） |
| `R`（背包内） | 旋转物品 90°（拖动中或悬停时） |
| 右键（背包内） | 分解该收集物 |
| `ESC` | 暂停 / 关闭面板 / 结算界面回标题 |
| `M` | 静音 |
| `R`（结算界面） | 重开 |

## 目标

1. 在**大厅**用账户配装：选 2 把武器、给每把配 0–3 个初始弹夹、选择带入局的数据（100 的倍数）。
2. 进入随机生成的**开放场地**（128×96 格、约 18 座墙段围合的空心建筑、96 个小掩体、13 群共 52 个敌人、82 个收集物）。
3. 敌人按**群落**分布：没被发现时围着巢穴打转，一旦惊动一群就会整群扑上来。
4. 搜刮发光容器，`TAB` 打开背包**右键分解**成「数据」（单位 NB）。
5. 用局内数据在背包里**制造弹夹**、**治疗回血**。
6. 找到撤离台（小地图上的青色标记），站进范围坚持 **6 秒**撤离：剩余数据入账、背包物资入库。
7. 死亡 = 本局物资与未花完的携带数据丢失，仓库与账户不受影响。

---

## 背包与物品

- 固定 **6×4 = 24 格**；物品尺寸**按种类固定**：常见 1×1 / 1×2 / 2×1，稀有的相位碎片 2×2、拓扑密钥 1×3，史诗的奇点残核 2×3、ATA 黑匣 3×2。
- **左键拖动**摆放，拖动时按 **R** 旋转；松手若冲突或越界会退回原位。
- 不在拖动时，按 R 可原地旋转悬停/选中的物品（空间不足会提示）。
- **右键分解**；容量显示为"已占用格数 / 24"（2×2 占 4 格）。
- 拾取时自动寻找第一个放得下的位置（含旋转），实在放不下才提示背包已满。

## 五种武器

| 键 | 武器 | 模态 | 弹夹 / 备弹 | 特性 |
|---|---|---|---|---|
| 1 | 共振霰弹 | 声学 | 6 / 2 夹 | 开火瞬间释放 66° 扇形冲击波，随距离衰减，近身击退 |
| 2 | 棱镜激光 | 光学 | 6 / 2 夹 | 开火即算出整条反射折线（最多弹墙 3 次），路径上所有敌人一次性受伤，单发 46 |
| 3 | 辐射投射器 | 热学 | 5 / 2 夹 | 命中点生成辐射场，3.2 秒内持续灼烧范围内敌人 |
| 4 | 轨道步枪 | 力学 | 12 / 2 夹 | 最朴素的高速动能弹，单发 34、后坐极小 |
| 5 | 电弧枪 | 电学 | 8 / 2 夹 | 命中后向附近敌人连锁 3 跳（60% / 40% / 25%） |

**弹药规则**：每局只能携带 2 把，其余武器锁死；备弹上限 = 2 个弹夹；换弹会**丢弃当前弹夹剩余子弹**；地图不掉弹药，弹夹只能用数据在背包里压制（25–70 NB / 1.5s）。

## 敌人

| 类型 | 威胁 | 行为 |
|---|---|---|
| 裂体 | 低 | 近战贴脸，数量最多 |
| 蚀甲体 | 中 | 慢速重击，血厚 |
| 突刺体 | 高 | 0.5s 蓄力后直线冲锋，命中 20 伤害并把你撞开 |
| 喷吐体 | 高 | 保持 230–420 距离，发射酸弹；弹体会被墙挡下 |

- 全场 **13 群 / 52 只**；每 5 群里有 1 群是精英群（只出蚀甲体 / 突刺体 / 喷吐体）。
- 远程敌人会绕圈保持射程，逼你找掩体或冲脸；开阔地硬拼很容易被冲锋 + 酸弹夹击。

---

## 生存规则

- **护盾 60**：优先全额吸收伤害，**溢出不会穿透到血量**；脱战 4.5 秒后以 30/s 回满。
- **耐力 100**：按住 `SHIFT` 奔跑；奔跑 21/s 消耗，松开 0.7s 后以 17/s 回复。耐力耗尽会强制走路，回到 28 才能再次奔跑。耐力未满时，玩家左侧显示半环耐力条（与身体留空隙）。
- **血量 100**：只能靠背包内治疗（50 NB / 3s）回满。
- **背包不暂停世界**：分解/治疗期间移动会中断，且背包中移速降为 55%——找安全角落再整理。
- **数据**：局内从"携带数据"开始；撤离后剩余数据退回账户（跨局）；死亡则丢失未花完的携带数据与全部本局物资。

## 渲染资源

`assets/` 下是 Blender 5.3 正交渲染的透明 PNG：

| 文件 | 用途 |
|---|---|
| `player.png` | 侧视 1:1 头身 Q 版（无手脚、悬浮）；游戏里只随准星左右翻转 |
| `w0..w4_top.png` | 五把武器的俯视贴图；以握把为旋转原点，全向旋转 |
| `w0..w4_side.png` | 五把武器的侧视图；HUD 武器槽与右下武器面板图标 |
| `weapons_lineup.png` | 五把武器的比例参考图 |

重新生成：在 Blender 中执行 `_blender/render_player.py` 与 `_blender/render_weapons.py`（会新建独立的 `EOFATA_*` 场景，不动你当前场景）。

## 当前限制

- 敌人四种（近战 / 重甲 / 冲锋 / 远程），不会无限刷新；没有 Boss。
- 局外有数据账户与仓库，但**武器不跨局保存**，没有永久武器成长。
- 音效为实时合成，首次点击后才会解锁音频上下文（浏览器策略）。
- 仅键鼠操作，未做手柄与移动端适配。
- 存档为账户数据 + 仓库物资 + 最佳战绩（localStorage）。
