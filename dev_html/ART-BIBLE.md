## 0. 之前为什么"不像一层"

把四类现有素材放在一起看，问题不是画得不好，是**四套语言**：

| 素材 | 描边 | 明暗 | 细节密度 | 色温 |
| --- | --- | --- | --- | --- |
| `assets/player.png` | 无 | 柔和高光渐变 | 中 | 冷（蓝灰 + 青） |
| `art_draft/enemies/zombie` | 粗黑描边 | 纯平涂 | 低 | 冷灰绿 |
| `assets/weapons_lineup.png` | 细描边 | 单色块 + 金属亮边 | 高 | 冷（近黑） |
| `assets/floor_tiles.png` | 无 | 完全平 | 极低 | 暖（米棕） |

四个变量各走各的，所以拼在一起"贴纸感"很重。
本次定调的做法是：**把这四个变量全部锁死成一套规则**，再让体积、剪影、配色去承载区分度。

## 1. 造型规则：低多边形

- 全部由**倒角方块 / 低边圆柱 / 低面球**拼成，倒角**只做 1 段**（一个斜切面，不做圆角过渡）。
- 圆柱 8 边、球体 8×5 段；**全部平直着色**（flat shading），不允许 smooth。
- 面数预算：整张场景 345 个 mesh / 约 6.1 千面。
  **单个角色 90–130 面**，单把枪约 150–250 面。
- **角色结构只有四块**：一个方块 = 头，一个方块 = 身体，两个方块 = 腿。
  不建手臂、不建手；面部只允许**贴片**（面罩 / 眼睛 / 嘴），不允许用几何堆细节。
  角色之间的区分只靠：头身比例、头部大小、主色、面部贴片。
- **玩家角色是人类，不是机器人**（攻击方/受击方都是血肉之躯）；机器人造型已废弃。
- 剪影优先：角色在 64px 高度仍要能靠"毛线帽 + 瘦 / 头盔 + 壮 / 大头 + 牙 / 窄高头 + 颌"区分。
- 细节只用**块面 + 贴片**做，不用雕刻、不用倒角分级、不用贴图花纹。

对应代码开关（`artbible_scene.py`）：

```python
LOWPOLY = True
LOBEVEL = 1        # 倒角段数
LOBW = 0.5         # 倒角宽度系数
LOSEG = 8          # 圆柱边数
LOSPHERE = (8, 5)  # 球体段数
```

> 想要更"棱"或更"方"，只改这四个数，整套资产一起变，不会散。

## 2. 渲染规则：三渲二

所有材质都是同一条节点链：

```
Diffuse(白) → Shader to RGB → ColorRamp(常量插值) → Emission → Output
                                  ↑ 0.00 暗部 / 0.30 中间调 / 0.76 亮部
```

- **只有 3 个色阶**，色阶之间是硬边，没有渐变、没有高光贴图。
- 暗部不是把基色压黑，而是 `基色 × 0.56 + 冷色偏移 (0.055, 0.075, 0.115)` ——
  所有物体共用同一个暗部配方，这是"同一层"最关键的一条。
- 建筑（地板/墙）把第三档阈值拉到 **0.99**，让大面积保持中间调，只靠投影和描边出结构，
  避免整面墙泛白。
- 色彩管理必须是 **Standard**（AgX / Filmic 会把颜色灰掉，三渲二会直接失效）。

### 描边

统一用**倒壳描边**（不是 Freestyle）：Solidify 向外 + 翻转法线 + 材质背面剔除，
描边色固定 `#16130F`（暖近黑，不用纯黑）。

| 类别 | 粗细 |
| --- | --- |
| 角色 / 敌人 | 0.019 m |
| 道具 | 0.013 m |
| 武器 | 0.012 m |
| 建筑 | 0.009 m |

## 3. 灯光规则

| 灯 | 方向 | 强度 | 颜色 |
| --- | --- | --- | --- |
| Key | 左前上方（俯角 ~45°） | 3.6 | 暖白 `#FFF9EF` |
| Fill | 右前 | 0.55 | 冷蓝 `#B8D6FF` |
| Rim | 后上方 | 0.8 | 暖 `#FFEBD6` |

一条固定光位负责全部镜头：正面中间调、顶面亮、右侧面暗部。
**永远不要为了单个物件换光**，换光就等于换图层。

## 4. 调色板

每个色相都只给「亮 / 中 / 暗」三档，三档之间明度差一致。

| 用途 | 亮 | 中 | 暗 |
| --- | --- | --- | --- |
| 地板 | `#C9B49A` | — | 勾缝 `#8A7660` |
| 墙体 | `#E9DFCF` | 压条 `#DCD0BB` | 踢脚 `#C6B69C` |
| 玩家 | 面板 `#525F73` | 机身 `#3D4757` | 深部 `#2E3540` |
| 僵尸 | 皮肤 `#8FAE6B` | 躯干 `#6E8A52` | 破布 `#4A5638` |
| 喷吐僵尸 | 皮肤 `#7FA8D2` | 躯干 `#5A7DA6` | 深部 `#36496A` |
| 武器 | 亮件 `#4B525C` | 枪身 `#33383F` | 钢件 `#B9C1CB` |
| 道具 | 木箱 `#A97C50` | 油桶 `#3F5F63` | 木箱暗 `#7A5736` |

**发光色只用于三种东西**：玩家面罩（青 `#86E9F2`）、喷吐僵尸口腔（紫 `#B98CFF`）、
可交互物（琥珀 `#F0B04C`）。其它地方一概不发光 —— 发光一多，视线就被拉散了。

## 5. 尺寸规范（1 单位 = 1 米）

- 地砖：2 m（对应游戏 2 格 × 32px）
- 墙高：2.15 m，墙厚 0.4 m
- 角色：1.78 m（游戏内绘制高度 55–64px）
- 武器：1.0–1.2 m（游戏内 40px，美术上刻意比真枪长，保证 40px 下剪影可读）
- 弹药箱 / 战利品箱：0.4–0.5 m
